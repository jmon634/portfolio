Mini Case Study: Vacation Planner Capstone

A quick deep-dive to show how I think through implementation and tradeoffs.

Problem & Constraints

Create a mobile experience for planning and organizing trips, while keeping the project maintainable and easy to demo for reviewers. Shipping a working release artifact was a priority.

Approach

I focused on clean separation of concerns, predictable user flows, and reliable persistence. Documentation and tooling (build + testing) were treated as part of the deliverable.

Key Decisions

  • Maintainability: structured components and consistent project organization.
  • Reliability: use persistence patterns to avoid data loss and support offline use.
  • Reviewability: published an installable APK for straightforward testing.
